# GeoBase：几何算法基础库

个人学习项目，基于 C++ 实现的工业级三维几何算法工具库。

面向 CAD、工业软件、三维仿真、几何算法求职方向打造。

## 已实现功能

### 数学基础库
- 统一浮点精度管理（EPS_ABS/EPS_REL）
- 角度与弧度互转、高精度圆周率常量

### Vector3 三维向量
- 基础构造、四则运算、标量运算
- 点积、叉积、模长、归一化
- 浮点鲁棒性处理
- 全套 GTest 单元测试覆盖

### Point3 点类型
- Vector3 别名实现，语义严格区分点与向量

### Matrix3 3×3 旋转矩阵
- 单位矩阵、X/Y/Z 轴旋转矩阵
- 矩阵乘法、转置、正交判断
- 行列式计算、伴随矩阵求逆
- 工业标准 Y-X-Z 欧拉角双向转换，处理万向锁与角度归一化
- 与 Matrix4 互相转换
- 全量单元测试 + 退化场景覆盖（零矩阵、奇异矩阵、极值场景）

### Matrix4 4×4 仿射矩阵
- 平移、旋转、缩放基础变换
- 矩阵乘法、转置、浮点近似相等判断
- 区分点与方向向量变换规则（w=1 / w=0）
- 仿射矩阵求逆、通用高斯消元求逆
- 透视投影、正交投影、LookAt 观察矩阵
- 完整单元测试与各类退化场景覆盖

### EulerAngles 欧拉角
- 标准 Y-X-Z 旋转顺序实现
- 角度归一化处理
- 万向锁检测与异常处理

### Quaternion 四元数
- 欧拉角 / 旋转矩阵 / 四元数 两两互转
- 四元数乘法、共轭、求逆、归一化
- 矩阵转四元数采用最大分量分支，保证数值稳定
- 非正交矩阵合法性校验、零四元数异常保护
- q/-q 等价性验证、大角度场景测试
- 全套 GTest 单元测试覆盖

### Plane 平面
- 点法式构造，构造自动归一化法线
- 点到平面有符号距离计算、点投影求解
- 点包含判断、空间侧分类（ON_PLANE / FRONT / BACK）
- 三点快速构造平面
- 全套 GTest 测试，覆盖法线未归一化等退化场景

### AABB 轴对齐包围盒
- 最小/最大点构造、中心点与半边长访问
- 点扩展、多 AABB 合并运算
- 点包含判断、三轴区间重叠相交检测
- 矩阵变换更新包围盒（8 顶点重算）
- 全套 GTest 测试，覆盖零尺寸、旋转畸变等退化场景

### Triangle3 三角形
- 三点构造，拦截退化三角形异常
- 顶点访问、法线计算、面积计算
- 重心坐标求解（点积法，规避符号丢失问题）
- 点包含判断、包围盒快速求解
- 全套 GTest 测试，覆盖共线退化、点在边上等场景

### Ray 射线
- 起点+方向构造，方向自动归一化、拦截零向量
- 参数化射线点求解
- 全套 GTest 单元测试覆盖

### 核心求交算法
- 射线-平面求交：自主推导，兼容平行、背面特殊场景
- 射线-AABB 求交：Slab 算法，处理方向分量为零退化情况
- 射线-三角形求交：Möller-Trumbore 算法，支持背面剔除
- 三角形-AABB 相交：13 轴 SAT 分离轴定理，预检测优化提速
- 全算法覆盖平行、共面、退化几何、内部发射等边界测试

### HitInfo 统一求交结构
- 统一封装交点 t 参数、坐标、法线数据
- 法线自动根据射线方向修正
- 所有几何图元统一 intersect 求交接口

### BVH 层次包围盒树
- 基础中点划分构建策略
- SAH 表面积启发桶划分优化
- 最近命中优先遍历、高效剪枝逻辑
- 叶子节点区间存储，降低内存开销
- 性能优异，万面模型加速比超 50 倍
- 全量单元测试，覆盖空场景、单图元、完全重合等退化场景

### Octree 八叉树
- 点云数据插入、递归节点分裂
- 空间半径查询、K 近邻搜索
- 深度、叶节点容量可控配置
- 全套 GTest 单元测试覆盖

### Kd-tree
- 中位数分割策略构建树结构
- 最近邻、K 近邻、半径范围查询
- 完整单元测试，附带与八叉树性能对比

### OBJ 文件加载器
- 标准顶点、面索引解析
- 兼容 OBJ 起始索引为 1 的规范
- 自动对四边形面进行三角剖分处理

### HEMesh 半边网格数据结构
- 完整半边、顶点、面核心拓扑结构
- 支持 OBJ 文件直接构建网格
- 全维度拓扑遍历（邻边、邻面、邻点、面内遍历）
- 边界边检测、边界环提取、网格封闭性判断
- 边翻转、边折叠、边分割核心网格操作
- 非流形保护、边界保护等鲁棒性处理
- 全套单元测试，覆盖空网格、单三角、非流形边等退化场景

### QEM 二次误差度量
- 平面误差矩阵构建、顶点误差计算
- 最优折叠位置求解，矩阵退化自动降级中点
- 边界顶点惩罚、特征边二面角约束保护
- 优先队列驱动贪心网格简化
- 全套 GTest 单元测试覆盖

### GJK 碰撞检测
- 支持函数、闵可夫斯基差核心实现
- 2D/3D 单纯形迭代进化逻辑
- 全覆盖退化测试（重叠、接触、点/线段退化、迭代超限保护）

### EPA 穿透深度计算
- 精准求解碰撞穿透深度与分离法线
- 全套单元测试覆盖各类碰撞场景

### BezierCurve 贝塞尔曲线
- de Casteljau 递推求值算法
- 曲线升阶、导数求解
- 单元测试覆盖端点插值、升阶不变性验证

### BezierSurface 贝塞尔曲面
- 张量积曲面求值实现
- 全套 GTest 单元测试覆盖

### RationalBezierCurve 有理贝塞尔曲线
- 齐次坐标架构实现、权重动态调节
- 支持标准圆形精确拟合
- 单元测试覆盖权重退化特殊场景

### BSplineCurve B 样条曲线
- Cox-de Boor 递推求值算法
- 高效节点区间查找、Boehm 节点插入
- 验证端点插值、局部支撑核心特性

### NURBSCurve NURBS 曲线
- 齐次坐标标准实现
- 支持高精度圆形拟合
- 全覆盖权重退化、极值场景单元测试

- 纯 C++ 原生实现，核心算法无第三方依赖
- 全程规范浮点精度管理，数值鲁棒性极强
- 全覆盖各类退化、边界、极值工业场景
- 150+ GTest 单元测试，分层覆盖正常/边界/异常场景
- 手写工业级标准核心几何算法，贴合 CAD 内核原理
- 支持与 OpenCASCADE 工业几何内核对标测试
- 兼顾算法原理学习、面试刷题、工业软件开发实战

3. 空间加速结构：BVH、八叉树、Kd\-tree
